DEOX paketlerini arşivle.

deox-repo/deoxpool/ içine eklenen .deb paketleri, GitHub Actions tarafından Internet Archive S3 API'sine yüklenir. API anahtarları bu herkese açık sayfaya konmaz; yalnızca Actions secrets olarak kullanılır.

Yükleme workflow'unu aç ↗ DEB paket klasörü ↗

Nasıl çalışıyor?

1

.deb dosyasını deox-repo/deoxpool/ dizinine ekleyin. Dosya adı <paket>_<sürüm>_<mimari>.deb biçiminde olmalı.

2

Değişikliği main dalına push edin. Workflow paketleri Archive.org'a yükler; mevcut paketleri tekrar yüklemek için Actions sayfasından workflow'u elle çalıştırın.

3

İşlem sonucunu GitHub Actions loglarından izleyin. Yükleme hedefi, repository variable IA_IDENTIFIER ile belirlenir.

Gizli ayarlar

Repository Settings → Secrets and variables → Actions altında aşağıdaki değerleri tanımlayın:

  • IA_S3_ACCESS_KEYRepository secret — Archive.org S3 access key
  • IA_S3_SECRET_KEYRepository secret — Archive.org S3 secret key
  • IA_IDENTIFIERRepository variable — Archive.org item ID

Önemli güvenlik notu: GitHub Pages kaynak kodu herkese açıktır. API/S3 key'lerini HTML, JavaScript, `.env` dosyası veya repository içindeki herhangi bir dosyaya yazmayın. Bu sayfa key toplamaz; yükleme sırasında anahtarlar yalnızca GitHub Actions secret'larından okunur.
