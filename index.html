Kurulum 3 adım

Herhangi bir Debian/Ubuntu sistemine depoyu ekle — bu sayfadaki komutlar kopyala-yapıştır çalışır.

1

İmza anahtarını ekle

Depo GPG ile imzalanır; apt bu anahtarı güvenirliste olarak kullanır.

curl -fsSL https://project-neox.github.io/Neox-Repo/neox-repo.gpg | sudo tee /usr/share/keyrings/neox-repo.gpg > /dev/null
2

Depoyu sources.list'e ekle

Depo girdisi tek satırdır; suite stable, bileşen main.

echo "deb [signed-by=/usr/share/keyrings/neox-repo.gpg] https://project-neox.github.io/Neox-Repo stable main" | sudo tee /etc/apt/sources.list.d/neox-repo.list
3

Güncelle ve kur

apt update imza ve checksum doğrulamalarını yapar; sonra paketi kur.

sudo apt update && sudo apt install neox-repo-setup
⚡ Tek komutla kurulum: Yukarıdaki 3 adımı otomatik yapan script:
curl -fsSL https://project-neox.github.io/Neox-Repo/setup-repo.sh | sudo bash
İstersen otomatik güncelleme timer'ini de kurar: … | sudo bash -s -- --enable-auto-update

Otomatik Güncelleme

Depoya yeni paket yüklendiğinde sistemin otomatik olarak haberi olsun. auto-update.sh, sadece bu depoyu yeniler ve depodaki tüm paketleri kurar/günceller.

🛠 Scripti kur

Depo eklendikten sonra otomatik güncelleyiciyi sisteme kur:

curl -fsSL https://project-neox.github.io/Neox-Repo/auto-update.sh | sudo tee /usr/local/bin/neox-repo-auto-update > /dev/null && sudo chmod +x /usr/local/bin/neox-repo-auto-update

⏰ systemd timer (önerilen)

Her saat başı otomatik çalışsın — saatlik, açılışta telafi eder:

curl -fsSL https://project-neox.github.io/Neox-Repo/neox-repo-auto-update.service | sudo tee /etc/systemd/system/neox-repo-auto-update.service > /dev/null curl -fsSL https://project-neox.github.io/Neox-Repo/neox-repo-auto-update.timer | sudo tee /etc/systemd/system/neox-repo-auto-update.timer > /dev/null sudo systemctl daemon-reload && sudo systemctl enable --now neox-repo-auto-update.timer
🔁 Alternatif — cron: 17 * * * * root /usr/local/bin/neox-repo-auto-update satırını /etc/crontab'e eklenebilirsin. Timer'ı izlemek için: systemctl list-timers neox-repo-auto-update.timer
